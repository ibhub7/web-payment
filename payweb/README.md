# BotPay - lightweight UPI pay web (GitHub Pages)

1. Edit `config.js`: UPI id/name, bots, plans, amounts.
2. Upload all files to a GitHub repo -> Settings -> Pages -> Branch `main` / root.

Main page (donate): `https://YOURNAME.github.io/REPO/`
Bot page: `https://YOURNAME.github.io/REPO/?bot=movies`
